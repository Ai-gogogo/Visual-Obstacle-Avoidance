# 第二轮双目标定验证 · 2026-11-19

本次检验 Camera A 与 B 校正后同一棋盘角点的上下偏差。每路 480 × 640 像素，纸棋盘有 9 × 6 个内角点。源录像标识为 36ad570e。384 对解码画面中，319 对都找到完整棋盘。按姿势去重后，54 对用于拟合，18 对从同一录像留出作验证。

| 指标 | 结果 |
| --- | ---: |
| 拟合重投影 RMS | 0.435 px |
| 留出角点校正前上下误差中位数 / P95 | 3.65 / 5.65 px |
| 留出角点校正后上下误差中位数 / P95 | 0.45 / 1.54 px |
| 每个姿势自身的 P95 在 2 px 以内 | 17 / 18 |
| 最差姿势 | 第 210 帧，P95 为 2.18 px |

总体达到本次设定的 2 px 目标。验证范围为这套固定机位、镜头和分辨率。桌面平面实验中，15 个抽样帧均未通过桌面留区验证，尚不能由棋盘对齐结果推断桌面拟合稳定性。绝对测距仍需实测棋盘格长和已知距离目标验证。

## 复核

在装有 NumPy 和 OpenCV 的 CV 环境，从仓库根目录运行：

```sh
python cv/results/stereo-calibration-2026-11-19/verify.py
```

parameters.json 保存 A/B 的相机矩阵 ka/kb、OpenCV 畸变系数 da/db、从 A 到 B 的旋转 R 和平移 T，以及图像宽高 size。T 的单位为一个棋盘格边长；换算为米时须乘以实测单格边长（米）。held-corners.csv 包含 18 个留出姿势在两幅原图上的 972 对亚像素坐标。脚本使用零视差校正、alpha=0，逐帧及汇总核对 validation.json。CSV 只含坐标。原始照片和录像留在本地。
