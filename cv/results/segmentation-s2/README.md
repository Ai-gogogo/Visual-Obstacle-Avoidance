# S2 审查记录 · 2026-11-21

基线为 S1 提交 `38bd53a`。Camera A 按相同索引选出置信度 ≥0.4 的物体和轮廓。
在同一帧内，测距和测高共享从原始公制深度提取的像素坐标与观测值。以轮廓的最小
外接矩形作为腐蚀的计算范围，矩形内仍按真实轮廓取样，孔洞保留。预览的空间和时间
滤波独立运行。

## 采样和回退

- 默认腐蚀半径为 2 px。内部有效观测少于 24 个时重试完整轮廓，以有限且大于零的深度计数。
- 测距另要求覆盖所选轮廓面积的 40%，且四分位距 ≤ 中位距离的 20%。失败后重试框中央 50%；框也失败则无读数。距离和 P10 来自同一批通过检验的像素。
- 测高要求支撑平面通过验证。腐蚀轮廓、原轮廓均不足 24 个有效像素时，使用原有框内高度规则。输出垂直于平面的高度中位数、P90 和超出误差带的比例。
- 具备掩码的物体测距成功时，worker 写入 `depth_m` 和 `nearest_depth_m`，有高度时写入 `height_above_plane_m`。纯检测权重沿用原有字段和棋盘单位换算精度。S5 负责服务端与 Agent 的新字段放行。

## 已知几何与回放

合成双腿物体的框中央露出 3.0 m 处的支撑面，框采样得到 3.0 m 和零高度。在轮廓边缘注入
0.3 m 飞点后，内部仍恢复中位距离 2.0 m、P10 距离 1.8 m、中位高度 1.0 m 和 P90 高度
1.2 m。单测另覆盖 23/24 像素边界、覆盖不足、深度混杂和倾斜平面的原图坐标。

真实 HTTP 核验使用同一对桌面录像图、真实 YOLO 权重及该对图像预计算的未滤波 RAFT 深度。
S1 纯检测与 S2 纯检测请求各 33,308 字节，去掉两路上传帧号和时间戳后 JSON 完全一致。
S2 分割请求含 9 个物体，其中 2 个有距离及 P10，6 个有高度。三个请求均返回 HTTP 204。
递归检查实际请求中的数组，只出现物体列表、框、已有特征向量、显示量程和未知凸起列表；
深度预览也与 S1 一致。另一项 HTTP 回归故意给空间、时间预览传入不同的深度，
并在两个强检测前插入弱检测，验证上报的距离、P10 和高度均来自正确物体的原始公制深度。

## CPU 后处理耗时

Apple M1 Pro，480 × 640。取 S1 同一录像前 37 对同步帧、YOLO11n-seg 实例轮廓、
未滤波的 RAFT 深度及沿用矩形前景扣除的支撑平面。每帧有 4–14 个通过置信度门槛的物体。
两种采样方式各预热一遍，交替先后顺序测 5 轮，每次从原始轮廓重新提取样本。
