# Presentation Team

Research, documentation, evaluation, and final demonstration materials for the Visual Obstacle Avoidance hackathon prototype.

## Research Files

- **Indoor Mobility Glasses - Complete Survey Results.xlsx** — source survey-results workbook.
- **Indoor Mobility Glasses - Research Report.xlsx** — research/report workbook.

These two spreadsheets are deliberately stored **only in this folder on the `presentation` branch**. They are not intended to be copied or merged into `main`.

The presentation branch also contains `AI Glasses - Completed Web Research.xlsx` at its root, which has been left unchanged.

## Team Responsibilities

1. Research the accessibility problem, existing products, and user needs. Cite sources and avoid unsupported claims.
2. Document the proposed dual-smartphone/WebRTC, YOLO/CV, LLM Agent, voice, and memory architecture.
3. Prepare system diagrams, demo scenarios, screenshots, and a backup demo recording.
4. Collect actual testing evidence from Web UI, CV, and Agent teams: FPS, latency, observed detection failures, and known limitations.
5. Create slides, speaking notes, and answers to likely questions from judges.

## Suggested Slide Order

Introduction → Problem → Existing Solutions → Proposed Solution → Architecture → CV Pipeline → Agent & Memory → Live Demo → Results & Limitations → Future Work.

## Safety Note

The prototype is an experimental visual-assistance demo, not a certified navigation aid. Do not claim that object detection measures distance accurately or that the system prevents collisions.
